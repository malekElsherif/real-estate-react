# Real Estate React 🏠

Frontend for a Real Estate Platform built with **React, TypeScript, and Vite**.

## Features

* 🔐 Login & Register
* 🏠 Browse and view properties
* ❤️ Favorites
* 📝 Rental & Purchase Requests
* 💬 Real-time Chat using Socket.IO
* 👨‍💼 Agent Dashboard
* 🛡️ Admin Dashboard

## Tech Stack

* React
* TypeScript
* Vite
* React Router
* TanStack React Query
* Axios
* Tailwind CSS
* Material UI
* Socket.IO

## Installation

```bash
npm install
npm run dev
```

The app runs on:

```text
http://localhost:5173
```

> Make sure the backend is running before using the application.
